Featured case study

JANIS, a creative operating system you talk to

JANIS stands for Jerilyn's Alternative Network for Immersive Storytelling. It is a conversational voice assistant and workspace suite for writers and worldbuilders, built so creators make more, not so a model makes it for them.

I own the product end to end: vision, positioning, feature architecture and a multi-phase roadmap. I designed the interaction flows, personality framework, behavioral principles and voice identity, then built the desktop prototype hands-on with Claude Code and shipped iterative releases.

Updates resolved real usability problems: voice persistence, microphone handling and how responses appear on screen. Higgsfield is part of the workflow for AI-assisted visual creation.
